# Astral

Клиент для Windows 10 и 11 (64-bit). Установщик, ярлыки и обновления с GitHub Releases.

Страница установки: [ressedich.github.io/astral](https://ressedich.github.io/astral)

## Установка

1. Откройте [последний релиз](https://github.com/ressedich/astral/releases/latest) и скачайте `Astral-Setup-<версия>.exe`.
2. Запустите установщик. Он ставится для текущего пользователя и не требует прав администратора.
3. На шаге **«Ярлыки»** отметьте, куда добавить Astral:
   - на рабочий стол;
   - в меню «Пуск».
   
   Обе галочки включены. Снимите ту, которая не нужна.
4. Запустите Astral.

Приложение оказывается в `%LOCALAPPDATA%\Programs\Astral`. Настройки и подписки пишутся в `%APPDATA%\Astral` и не удаляются при обновлении.

Режим TUN при включении запрашивает права администратора (драйвер Wintun). Режим PROXY — нет.

## Обновления

Установленная Astral сама проверяет GitHub Releases через несколько секунд после запуска. Если версия новее, она скачивается в фоне. Дальше можно перезапустить приложение из окна или из **Настройки → Система**.

Пока обновление не поставлено, его можно отложить: оно установится при следующем выходе из Astral. Подписки и настройки сохраняются.

Кнопка **«Релизы»** в том же разделе открывает страницу загрузки, если автоматическая проверка недоступна.

## Как выложить новую версию

Номер в `package.json` и тег должны совпадать.

```powershell
# version в package.json уже 1.0.3
git add -A
git commit -m "Astral 1.0.3"
git tag v1.0.3
git push origin master --tags
```

GitHub Actions собирает установщик и прикрепляет к релизу три файла:

- `Astral-Setup-1.0.3.exe`
- `Astral-Setup-1.0.3.exe.blockmap`
- `latest.yml`

После этого уже установленные копии видят обновление. Релиз должен открываться без входа в GitHub: с приватного репозитория приложение получает 404 и написать, что релиз недоступен.

## Удаление

«Установка и удаление программ» → Astral. Ярлыки рабочего стола и меню «Пуск» удаляются вместе с приложением. Каталог `%APPDATA%\Astral` остаётся.

Сборка установщика описана в [README-DIST.md](README-DIST.md).
