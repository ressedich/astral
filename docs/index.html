Установка
для Windows

Один установщик. Ярлык на рабочий стол и в меню «Пуск» — по желанию. Новые версии приходят сами из GitHub Releases.

Скачать Astral Все версии

Windows 10 и 11, 64-bit. Файл называется Astral-Setup.

Как поставить

  1. Скачайте последний Astral-Setup и запустите его. Права администратора для установки не нужны.
  2. На шаге «Ярлыки» оставьте или снимите «Добавить Astral на рабочий стол» и «Добавить Astral в меню Пуск».
  3. Запустите Astral. Приложение лежит в локальной папке программ текущего пользователя.

Обновления

  • Astral сама проверяет GitHub через несколько секунд после запуска.
  • Новая версия скачивается в фоне. Установка — кнопкой «Перезапустить» или в Настройки → Система.
  • Подписки и настройки сохраняются. Ярлыки, которые уже есть, обновление не пересоздаёт.

Как выложить обновление

  1. Поднимите version в package.json.
  2. Отправьте тег с тем же номером: v1.0.3 для версии 1.0.3.
  3. GitHub Actions приложит установщик и latest.yml к релизу. Установленные копии заберут его сами.

Релиз должен открываться без входа в GitHub. Иначе приложение не сможет его скачать.

Удаление — через «Установка и удаление программ». Данные остаются в %APPDATA%\Astral.
